# LVTD organization profile

The public profile for [LVTD on GitHub](https://github.com/LVTD-LLC).

Edit [`profile/README.md`](profile/README.md) to update the organization overview.
Profile images live in `profile/assets/`; use absolute raw GitHub URLs so they
render correctly on the organization page as well as in this repository.

Keep project descriptions specific, link only to public repositories, and check
current product details against [lvtd.dev](https://lvtd.dev). Use ASCII copy and
keep the profile readable on mobile and in both GitHub themes.

Changes pushed to the default branch are published automatically by GitHub.
